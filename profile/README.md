## Featured Libraries

### Flutter & Dart

**[flutter_debounce_throttle](https://github.com/brewkits/flutter_debounce_throttle)**
Traffic Control System for your app architecture. Stop double-taps, spam API calls, and button hammering.
- Zero dependencies, 500+ tests
- Type-safe & production-ready
- Includes hooks variant & pure Dart

**[native_workmanager](https://github.com/brewkits/native_workmanager)**
High-performance background tasks without Flutter Engine. Native Workers save 90% RAM.
- Survives app kills & reboots
- Built with Kotlin Multiplatform
- iOS & Android native workers

### Kotlin Multiplatform

**[Grant](https://github.com/brewkits/Grant)**
Headless Permission Manager for KMP. Clean Architecture & ViewModel-first.
- Fixes Android Dead Clicks
- iOS Info.plist validation
- 14 permission types

**[kmpworkmanager](https://github.com/brewkits/kmpworkmanager)**
Unified API for background tasks. One codebase for WorkManager + BGTaskScheduler.
- Task Chains support
- 60-86% faster HTTP ops
- Built-in security

**[KRelay](https://github.com/brewkits/KRelay)**
Type-safe bridge from shared KMP code to native platforms.
- Memory-leak free
- Sticky Queue support
- Perfect for Toast, Navigation
